# Screenshot Evidence

The folders in this directory contain curated screenshots from the working lab and its troubleshooting process.

| Folder | Contents |
|---|---|
| `00-vm-setup` | DC01 VM settings, Add Roles wizard, CLIENT01 before joining the domain |
| `01-active-directory` | OU structure and built-in groups |
| `02-dns-domain-join` | DNS zones, DC records, and the domain-join dialog |
| `03-file-server` | Share folder structure and Finance share permissions |
| `04-gpo-drive-mapping` | Item-level targeting for the drive-map GPO |
| `05-gpo-control-panel` | Policy configuration, filtering, group members, `gpresult`, `whoami /groups`, and validation |
| `06-account-security` | Locked-out sign-in, ADUC unlock, and PowerShell lockout search |
| `07-software-deployment` | 7-Zip in Installed apps |
| `08-dhcp-networking` | DHCP console, scope, binding, scope options, lease, and VMware network editor |
| `09-troubleshooting` | APIPA, service state, static-IP test, binding, renew failure, and server statistics |
| `extras` | Low-resolution crops: setup licence error and two NTFS dialogs |

Before publishing new screenshots, remove passwords, keys, personal email addresses, unrelated host paths, and other private information. Windows evaluation notices and lab-only usernames may remain when they provide useful context and are not personal identifiers.
