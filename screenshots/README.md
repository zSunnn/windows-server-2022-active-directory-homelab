# Screenshot Evidence

The folders in this directory contain curated screenshots from the working lab and its troubleshooting process.

| Folder | Contents |
|---|---|
| `01-active-directory` | OU, domain, and group membership |
| `02-dns-domain-join` | DNS zone, domain join, and hostname validation |
| `03-file-server` | Share creation, NTFS permissions, and access testing |
| `04-gpo-drive-mapping` | GPO link, item-level targeting, and mapped drive |
| `05-gpo-control-panel` | Policy configuration, filtering, failure, and validation |
| `06-account-security` | Lockout policy, locked account, and recovery |
| `07-software-deployment` | GPO package and installed application |
| `08-dhcp-networking` | DHCP configuration, final topology, and successful lease |
| `09-troubleshooting` | APIPA, missing Discover traffic, binding, and renew failure |

Before publishing new screenshots, remove passwords, keys, personal email addresses, unrelated host paths, and other private information. Windows evaluation notices and lab-only usernames may remain when they provide useful context and are not personal identifiers.
